# Changelog

## 1.0.1 - 2026-09-20

- Refresh the tested framework and development dependency baseline.
- Publish the PHP SDK maintenance release.

## 1.0.0 - 2026-08-28

- Publish the first stable Slim SDK on PHP Core 1.x.
- Support PHP 8.2 through PHP 8.5 and PHPUnit 11–13.
- Report SDK version 1.0.0 in telemetry.

## 0.1.0 - 2026-08-12

- Add Slim 4 PSR-15 request middleware.
- Add customer and consuming-application resolvers.
- Add normalized route, exception and safe request-context capture.
- Add synchronous and file-buffered delivery backed by Apirelio PHP Core.
